# EduMongolia

Монгол, англи хэлтэй сургалтын вэб. Сургуулиас гадуурх гэрийн багш, танхимын төв, онлайн багш, тэтгэлэг, хөнгөлөлт, сурагч ба багшийн бүртгэл. Төслийн домайн: [edumongolia.com](https://edumongolia.com).

## Локал дээр ажиллуулах

```bash
npm install
npm run dev
```

Хөгжүүлэлтийн сервер `3847` порт дээр нээгдэнэ.

## Хятад дахь их сургууль

1-р үе шат. Лавлах, хөтөлбөр, тэтгэлэг, CSCA-ийн нийтлэгдсэн өдөр, элсэлтийн шалгуур. Төлбөр, доод оноо, хугацааг зохиогоогүй. Supabase холбоогүй.

`/china-universities` дээр 2026 оны 1 сарын 21-ний China Link зарлалын 2-р хавсралтаас 295 хүлээн авагч, мөн хамтрагч DongXueJi-ийн нийтийн жагсаалтаас 256 сургууль байна. DongXueJi-ийн нээлттэй 114 хөтөлбөр дээр чиглэл, суудлын тоо, хугацаа, өргөдлийн хуудас харагдана. Эхэд нь байхгүй хэлний оноо, голч, насыг хоосон үлдээнэ. China Link-ийн хөтөлбөрийн нөхцөл `/china-scholarships` дээр байна.

`/china-universities/registry` дээр Боловсролын яамны 2026 оны 6 сарын 17-ны жагсаалтын 3,196 сургууль байна. Код, хятад нэр, муж, байршил, эрхлэх байгууллага, түвшин л нийтлэгдэнэ. Гадаад оюутан авдаг эсэх, монгол нэр, төлбөр, элсэлтийн огноог файлд байхгүй тул хоосон. Импорт: `python3 scripts/import_moe_registry.py`.

`/china-cities` дээр DongXueJi зураг эсвэл танилцуулгатай хотын амьдрах орчин, `/china-videos` дээр тэдний нийтэлсэн видео байна. Хамтрагчийн зураг, танилцуулга тухайн сургуулийн хуудсанд гарна. Монголоор хянагдаагүй текстийг орчуулаагүй.

- `/study-abroad/china` — эхлэл
- `/china-universities` — хүлээн авагч их сургууль
- `/china-programs` — хөтөлбөр
- `/china-scholarships` — Хятадын тэтгэлэг
- `/eligibility-checker` — шалгуур

Хуучин гэрийн багш, төв, `/scholarships` хуудас хэвээр. Тайлбар `docs/arhitektur.md`.

## Бүтэц

- `app/` — нүүр, гэрийн багш, төв, тэтгэлэг, бүртгэл
- `components/` — толгой, хөл, хуудасны харагдац
- `lib/content/` — багш, төв, хөтөлбөрийн жишээ
- `lib/i18n/` — монгол, англи үг
- `netlify.toml` — Netlify дээрх бүтээх тохиргоо

Нүүрэнд ангиллууд хэвтээ гүйлгэлтээр байна. Гэрийн багшийг боловсролын зэрэг, хичээлийн ангиллаар шүүнэ. Сурагч, багшийн бүртгэл, диплом, курсын ажил, бие даалт, төслийн захиалга **Админ самбар** дээр гарна. Багшийн цагийн хуваарь **Багшийн мэдээлэл** дээр байна. Англи хэлний вакуум аялал **Аялалтай сургалт** дотор, захиалга нь Booking Mongolia дээр. Бүртгэл тухайн хөтөч дээр үлдэнэ.

## GitHub ба Netlify

Энэ кодыг GitHub репо болгосны дараа Netlify-д холбоно.

1. GitHub дээр `edumongolia` нэртэй репо үүсгээд энэ кодыг оруул.
2. [Netlify](https://app.netlify.com) → **Add new site** → **Import an existing project** → GitHub репогоо сонго.
3. Build тохиргоо `netlify.toml`-оос авна: `npm run build`, publish `.next`. Next.js-ийг Netlify өөрөө OpenNext-ээр ажиллуулна. Plugin хувилбар бүү тогтоо.
4. Сайт `*.netlify.app` дээр нээгдсэний дараа **Domain management** → **Add a domain** → `edumongolia.com`.
5. `www.edumongolia.com`-ийг мөн нэм. `netlify.toml` www-г apex руу 301-ээр явуулна.
6. Домайны DNS-ээ (registrar) Netlify-ийн заасан бичлэг рүү заа:
   - оройн домайн `edumongolia.com`: `A` бичлэг `75.2.60.5`, эсвэл `ALIAS`/`ANAME`/`CNAME` `apex-loadbalancer.netlify.com`
   - `www`: `CNAME` таны `*.netlify.app` хаяг руу
7. DNS шалгагдмагц Netlify Let’s Encrypt сертификатыг өөрөө гаргана.

Домайн, Netlify, GitHub данс энд холбогдоогүй. Дээрх алхмыг өөрийн бүртгэлээр баталгаажуулна. Нууц үгээ чат руу бүү явуул.
