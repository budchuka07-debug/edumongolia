Part B — Oxidation and reduction (REDOX)

A redox reaction is a reaction in which oxidation and reduction happen at the same time. At this level, use oxygen transfer and electron transfer to recognise them.

OXIDATION
• Gain of oxygen
• Loss of electrons
• Oxidation number increases
REDUCTION
• Loss of oxygen
• Gain of electrons
• Oxidation number decreases

Example: magnesium reacts with oxygen

2Mg+O₂→2MgO
Magnesium: 0 → +2
Mg loses 2 electrons: it is oxidised.
Oxygen: 0 → −2
O gains electrons: it is reduced.

Electron transfer model: Mg → Mg²⁺ + 2e⁻   |   O + 2e⁻ → O²⁻ (shown per oxygen atom). In O₂, both oxygen atoms gain electrons.

Teacher extension

Ask learners to explain which species is oxidised and which is reduced in each redox equation. Encourage them to compare oxidation numbers before and after the reaction.

Fe + CuSO₄ → FeSO₄ + Cu
Iron: 0 → +2 (oxidised). Copper: +2 → 0 (reduced).
CuO + H₂ → Cu + H₂O
Copper: +2 → 0 (reduced). Hydrogen: 0 → +1 (oxidised).
