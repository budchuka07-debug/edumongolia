# Элсэлтийн шалгуурын дүрэм

Код: `lib/marketplace/eligibility.ts`. Туршилт: `lib/marketplace/eligibility.test.ts`.

Гурван үр дүн:

1. **Тохирч байна.** Тухайн хичээлийн жилийн нийтлэгдсэн тоо бүгд бий, сурагч бүгдийг хангасан. Сонголтот шалгалт хангаагүй байж болно.
2. **Нэмэлт мэдээлэл хэрэгтэй.** Заавал шалгалтын тоо нийтлэгдээгүй, эсвэл сурагч оруулаагүй, эсвэл голчийн хэмжүүр 4, 5, 10, 100 биш. Дутуу оноог тэг гэж тооцохгүй.
3. **Хангахгүй.** Нийтлэгдсэн нас, боловсрол, голч, заавал хэл, заавал CSCA, эсвэл нийтлэгдсэн төлбөр төсвөөс өндөр.

Бусад дүрэм:

- Сонголтот шалгалт (`mandatory = false`) унагаахгүй.
- Нэг бүлгийн хэлний шалгалтаас нэгийг хангахад бүлэг тэнцэнэ.
- Хот, зэрэг, мэргэжил, сургалтын хэл нь шүүлт. Таарахгүй хөтөлбөр жагсаалтад орохгүй. Энэ нь их сургуулийн дүрэм биш.
- Шалгагч зөвхөн сонгосон хичээлийн жилийн мөрийг уншина.
- Их сургуульд холбоогүй тэтгэлэг тусдаа харагдана. Хөтөлбөр дээр автоматаар наахгүй.
- Үр дүн элсэлт, тэтгэлэг, виз батлахгүй.

Одоогийн каталогийн хөтөлбөрүүд доод оноо, төлбөргүй тул «тохирч байна» гарахгүй. «Нэмэлт мэдээлэл хэрэгтэй» гарна.
