# Боловсролын яамны бүртгэл

Supabase холбоогүй. Сайт `data/moe/2026-06-17/institutions.json` уншина. SQL-ийг дараа нь `supabase/seeds/moe-2026-06-17.sql` файлаас оруулна.

## Эх

Боловсролын яам, 2026 оны 6 сарын 18-ны зар. Жагсаалтын өдөр 2026 оны 6 сарын 17.

- Зар: http://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/t20260618_1441074.html
- Ердийн сургууль: `data/moe/2026-06-17/regular.xls`
- Насанд хүрэгчдийн сургууль: `data/moe/2026-06-17/adult.xls`

Дахин унших:

```bash
python3 scripts/import_moe_registry.py
```

Скрипт 2,952 + 244 = 3,196, үүнээс бакалавр 1,412, мэргэжлийн дээд 1,540 гэж шалгана. Тоо зөрсөн бол файл бичихгүй.

## Юу нийтлэгдсэн бэ

Код, хятад нэр, муж, байршил (`所在地`), эрхлэх байгууллага, түвшин, `民办` тэмдэглэл. Бусад тэмдэглэлийг тэмдэглэлээр нь үлдээнэ. Хоосон тэмдэглэлийг төрийн сургууль гэж үзэхгүй.

## Юу хоосон бэ

Монгол нэр, англи нэр, вэбсайт, хаяг, солбицол, оюутны тоо, түүх, хөтөлбөр, төлбөр, элсэлтийн огноо, хэлний оноо, тэтгэлэг. Эдгээрийг орчуулгаар бөглөхгүй. Хуудсан дээр «Албан ёсоор мэдээлэл одоогоор нийтлэгдээгүй.» гэж гарна.

`international_student_status` нь `unknown`. Жагсаалтад орсон нь гадаад оюутан авдаг гэсэн үг биш.

## Хуудас

- `/china-universities/registry` — хайлт, муж, түвшин
- `/china-universities/registry/[код]` — монгол профайл
- Админ самбар — дутуу талбар, энэ хөтөчийн төлөв

China Link болон DongXueJi хуучин хуудсаараа үлдэнэ. Нэр давхцвол профайл дээр холбоос гарна. Тэдний төлбөр, суудлыг яамны мөр луу хуулахгүй.

## Дараа нь

Хөтөлбөр, төлбөр, тэтгэлэг, шаардлагыг сургууль бүрийн албан эхээс тусад нь оруулна. Админы нийтлэх шийдвэр бүх зочдод хүрэхэд Supabase хэрэгтэй. Одоогийн админы төлөв зөвхөн тухайн хөтөчид хадгалагдана.
