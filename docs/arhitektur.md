# 1-р үе шатны тайлан

## Одоогийн төслийн шалгалт

- Хүрээ: Next.js 16.4.5, React 19, Tailwind CSS 4, shadcn/base-ui. `app/` чиглүүлэгч.
- Өгөгдөл: `lib/content/` доторх TypeScript. PostgreSQL, Supabase, Cloudinary байхгүй.
- Хэл: монгол, англи. Сонголт хөтөч дээр хадгалагдана. Хятад нэр шинэ каталогт гурав дахь талбар.
- Netlify: `netlify.toml`. Бүтээлт `npm run build`, Node 22, `www`-г `edumongolia.com` руу 301.
- Маягт: сурагч, багшийн бүртгэл, цаас захиалга хөтөч дээр үлдэнэ. Серверийн бүртгэл байхгүй.
- SEO: хуудасны гарчиг, тайлбар. Canonical, Open Graph, sitemap өмнө нь байгаагүй.
- Хуучин `/scholarships` нь гэрийн багшийн жишээ тэтгэлэг. Үүнийг солиогүй.
- Хуучин `/programs/foreign`, `/programs/international`, `/programs/travel`, `/programs/english` хэвээр.
- Давхардал: Хятадын тэтгэлгийг хуучин тэтгэлгийн карт дээр нэмээгүй. Шинэ каталог тусдаа.

## Юу нэмэгдсэн

| Зам | Үүрэг |
| --- | --- |
| `/china` | Хятад дахь сургалтын нүүр |
| `/universities`, `/universities/[slug]` | Их сургуулийн лавлах, дэлгэрэнгүй |
| `/programs`, `/programs/[slug]` | Хөтөлбөр. Хуучин төрөл хэвээр |
| `/programs/compare` | 2–3 хөтөлбөр зэрэгцүүлэх |
| `/study/scholarships`, `/scholarships/[slug]` | Тэтгэлэг. Жил тусдаа |
| `/eligibility` | Шалгуур |
| `/admission-guide`, `/admission-guide/[slug]` | Тайлбар, шалгалт |
| `/study/inquiry` | Зөвлөгөө. Хөтөч дээр, серверт явахгүй |

Өгөгдөл: `lib/marketplace/`. Дэлгэц: `components/marketplace/`. SQL: `supabase/schema.sql`, `supabase/rls.sql`. Supabase клиент суулгаагүй.

## Өгөгдлийн зарчим

- Төлбөр, тэтгэлгийн мөнгө, GPA, HSK, IELTS, TOEFL, CSCA-ийн доод оноо, элсэлтийн хугацааг зохиогоогүй. Хоосон талбар дэлгэц дээр «Их сургууль тодорхойлоогүй» эсвэл «Нийтлэгдээгүй».
- 2026/2027 ба 2027/2028 тусдаа мөр. Нэгийг нөгөөд хуулахгүй.
- Улсын тэтгэлгийг их сургуульд автоматаар наахгүй. Холбоо баталгаажаагүй бол хоосон.
- CSCA-ийн шалгалтын өдрийг 2026-11-08-нд [csca.cn](https://www.csca.cn/) нүүрээс авсан. Оноог аваагүй.
- Их сургуулийн нэр, хот, үүссэн он, сайт нь үзүүлэн. Эх сурвалж «баталгаажуулалт хүлээгдэж байна».
